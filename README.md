## Antigravity 개요 (Antigravity Overview)
* **변화 (The Shift):** 고립된 로컬 코드 Assistant에서 엔터프라이즈 에이전트 플랫폼 기반의 통합된 서버측 에이전트 하네스로의 전환임
* **비전 (The Vision):** 순수 생성형 모델과 자율 소프트웨어 엔지니어링 간의 간극을 해소하는 것임

"우리가 나아갈 방향을 이해하기 위해 한 걸음 물러서서 큰 그림을 봄. Antigravity의 핵심 비전은 순수하고 독립적인 생성형 모델과 진정한 자율 소프트웨어 엔지니어링 사이의 간극을 좁히는 것임. 학습을 진행하는 동안 이 핵심 변화를 항상 염두에 두어야 함. 단순하게 코드 라인을 제안하는 고립된 로컬 코드 Assistant에서 벗어나, 멀티 파일 엔지니어링 작업을 안전하고 투명하게 처리하도록 설계된 통합 서버측 에이전트 하네스로 전환하고 있음."

## Antigravity? (What is Antigravity?)
* **에이전트 하네스 (Agentic Harness):** 자연어 의도를 멀티 파일 엔지니어링 작업으로 변환함.
* **결정론적 제어 (Deterministic Control):** 추측을 구조화된 계획, 실행 원장(execution ledger), 시각적 차이 표시로 구현함.
* **서버측 런타임 (Server-Side Runtimes):** 로컬 워크스테이션에서 벗어나 무거운 실행 및 테스트 부하를 서버 측에서 실행함.

---

## 설치에서 사용 준비 단계 요약
1. **설치 (Installation):** 경량 로컬 CLI 도구(`agy`) 또는 IDE 확장 프로그램 설정함
2. **엔터프라이즈 SSO (Enterprise SSO):** 조직의 ID 제공자를 통한 안전한 인증을 거침
3. **프로젝트 연결 (Project Linking):** 활성 로컬 디렉토리를 승인된 Google Cloud 프로젝트 ID에 바인딩함

## 워크스페이스 구조
* **01 의도 입력 패널 (INTENT INPUT PANEL):** 아키텍처 목표를 정의하는 자연어 프롬프트 인터페이스임
* **02 컨텍스트 서랍 (CONTEXT DRAWER):** 에이전트가 현재 인식하고 있는 파일, 문서, 티켓을 보여주는 사이드바임
* **03 오픈 IDE 런처 (OPEN IDE LAUNCHER):** 주요 개발 환경 내에서 워크스페이스를 즉시 열 수 있는 우측 상단의 빠른 액세스 제어 기능임

---

## 프롬프트 투 디프 생애주기 (The Prompt-to-Diff Lifecycle)
* **Phase 1: 추론 계획 (Reasoning Plan):** 에이전트가 자연어 프롬프트를 다단계 작업 로드맵으로 분해함.
* **Phase 2: 실행 디프 (Execution Diff):** 플랫폼이 샌드박스 상태에서 파일 수정을 빌드하고 포맷함.
* **Phase 3: 인간 승인 (Human Approval):** 변경 사항이 로컬 파일에 반영되기 전에 사이드바 방식의 코드 디프를 검토함.

---

## 사용자 인터페이스 탐색 (Navigating the User Interfaces)
* **CLI (`agy`):** 빠른 스크립트 생성 및 리팩토링 작업을 위해 터미널 네이티브로 실행함
* **IDE Extensions:** 인라인 계획 및 검토를 위해 매일 사용하는 편집기 내부에 임베디드된 패널임
* **Web Command Center:** 여러 스쿼드에 대한 광범위한 다중 관리 및 관리자 제어를 위한 중앙 집중형 브라우저 허브임

---

## 토큰 경제학 및 컨텍스트 마스터하기 (Mastering Token Economics & Context)
* **과도한 붙여넣기 방지:** 전체 코드 디렉토리를 프롬프트에 붙여넣지 말고, 에이전트가 파일을 동적으로 검색하도록 유도하는 것이 좋음.
* **성능 최적화:** 컨텍스트 창을 간소화하여 더 빠른 응답 시간과 높은 추론 정확도를 보장함.
* **참조 활용:** 대상 태그와 커넥터를 사용하여 에이전트를 관련 모듈에 직접 연결함.

## 첫 실행 문제 해결 (Troubleshooting First-Run Pitfalls)
* **인증 시간 초과 (Authentication Timeouts):** 기업 토큰이 만료된 경우 `agy login`을 통한 빠른 재인증을 진행함
* **권한 경고 (Permission Warnings):** 파일 액세스가 차단되었을 때 활성 Google Cloud 프로젝트 바인딩을 확인함
* **세션 리셋 (Session Resets):** 멈춘 에이전트 루프를 재시작하기 위해 로컬 캐시 상태를 안전하게 지움
